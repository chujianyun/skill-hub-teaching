- R1：只允许 root/admin、15168466666/test、15168488888/test 登录；无需改密；刷新、退出、角色路由正确，审核深链登录后返回。
- R2：Skill 目录、搜索筛选、详情、文件夹/拖入/ZIP 上传、语义版本、历史下载与计数保持原功能。
- R3：员工草稿、提交、撤回、审核通过/驳回、修改重提、审核记录、红点及文件差异完整；管理员直接发布。

- R5：管理员和超管治理、上下架、删除；超管只读审阅，不承担租户内审核。
- R6：删除用户中心、改密、租户/员工/部门维护和 OAuth/客户端专用接口；超管只保留只读租户选择。
- R7：开发和测试库隔离，幂等种子不覆盖已有数据，重启后会话、包与业务记录仍可用。
- R8：类型检查、构建、API 和浏览器测试可执行；本地及 Docker 启动说明、三个账号和样例可用。

## UI 契约

| 角色/场景 | 路由/承载 | 操作与约束 |
|---|---|---|
| 未登录 | /login 独立页 | 账号卡片填入、用户名、密码、登录、错误提示 |
| 普通用户 | /workspace/skills、/workspace/my-skills、详情独立页 | 上传弹窗、查看可见 Skill、下载、自己的草稿与审核流程；无审核或超管菜单 |
| 租户管理员 | /tenant/skills、/tenant/my-skills、/tenant/reviews、审核详情 | 分类与治理、上传直接发布、审核通过/驳回，保留原筛选和版本表 |
| 超管 | /admin/skills、/admin/skills/:id | 只读租户下拉、所有 Skill 管理与上下架删除，不允许上传/审核 |
| 审核链接 | /skills/review/:versionId | 未登录先登录回跳；管理员进入审核页；所有者/超管只读 |
