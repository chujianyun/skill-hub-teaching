`pnpm run setup` 会依次执行 dev:db / build / db:deploy / db:seed；`pnpm run dev` 通过 `scripts/dev.mjs` 同时启动 server 与 web 子进程；`scripts/dev-db.mjs` 需先有 `docker-compose.dev.yml` 且 Docker 已运行；`scripts/verify-docker.mjs` 默认访问 `http://localhost:8081`（可通过 `DEMO_URL` 覆盖），支持 `--restart` 参数触发 server 重启后再校验会话与包内容持久化。
