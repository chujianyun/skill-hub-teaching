- 脚本统一采用 ESM 语法（`import` / `export`）并以 `.mjs` 后缀命名，通过 `node scripts/<name>.mjs` 直接执行而非经 pnpm script 包装。
- 对外部命令的调用封装为小函数或循环，并通过检查 `spawnSync` 返回的 `status` 决定是否 `process.exit(status ?? 1)`，保证失败即退出。
- SIGINT/SIGTERM 信号被捕获后向所有子进程发送 `SIGTERM` 并设置 `process.exitCode`，实现优雅停止。
- Docker 相关操作固定使用 `-f docker-compose.dev.yml` 指定开发编排文件，避免误触生产 compose。
- 示例 Skill 遵循 YAML frontmatter（name/description）+ Markdown 正文的结构，并通过 `references/` 目录存放被正文引用的模板。
