本模块由三类互不依赖的资产组成：
- `scripts/`：四个独立的 ESM 脚本（`.mjs`），通过 `node scripts/*.mjs` 直接执行，分别承担不同职责——`dev.mjs` 用 `pnpm --filter` 并行启动 `@skill-hub/server` 与 `@skill-hub/web` 并转发 SIGINT/SIGTERM；`setup.mjs` 复制 `.env.example` 后顺序调用 `dev:db`、`build`、`db:deploy`、`db:seed`；`dev-db.mjs` 通过 `docker compose -f docker-compose.dev.yml` 拉起 Postgres 并在其不存在时创建 `skill_hub_demo_test` 库；`verify-docker.mjs` 作为端到端冒烟测试，使用 `fflate` 构造 ZIP、通过 `/api/auth/login` 登录并以 admin cookie 上传/下载 11 MiB 包校验持久化。
- `docs/migration-spec.md`：以 R1–R8 需求条目 + UI 契约表格形式定义演示版的验收基线，是 `verify-docker.mjs` 中硬编码账号（root/admin、15168466666/test、15168488888/test）的来源。
- `examples/hello-skill/`：一个符合 Skill Hub 规范的示例技能包，`SKILL.md` 含 YAML frontmatter（name/description）与正文指令，`references/template.md` 为引用模板。
依赖方向单向：脚本仅调用外部工具（pnpm、docker、Node stdlib），不引入项目源码；示例包被服务器作为可上传资源消费。
