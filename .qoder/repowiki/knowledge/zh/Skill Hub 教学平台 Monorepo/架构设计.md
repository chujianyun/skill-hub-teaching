顶层以 pnpm workspace（`packages: apps/*, packages/*`）将四个子模块串联：`server`（NestJS API）、`web`（Vite+React 控制台）、`shared_package`（TS 类型/常量库）与 `scripts_and_docs`（本地开发、数据库初始化、验收文档）。跨子模块的契约由 `shared_package` 提供，前后端共用同一份 Skill 包规范与认证类型；构建与测试通过根 `package.json` 的 `pnpm -r build` / `typecheck` 与 `--filter @skill-hub/server|@skill-hub/web` 分发到各子包。运行时依赖由 `docker-compose.yml` 统一编排：PostgreSQL → server（暴露 `/api/health`）→ web（反向代理至 server），并挂载 `demo_packages` 卷承载私有 Skill 上传目录。TypeScript 编译选项集中在 `tsconfig.base.json`，所有子包继承该基配置。
