- 业务枚举值与其中文展示文案成对维护，使用 `Record<Enum, string>` 常量（如 `SKILL_VERSION_STATUS_LABELS`、`SKILL_VISIBILITY_LABELS`、`SKILL_REVIEW_ACTION_LABELS`）。
- 校验类函数统一返回 `{ name, description }` 或 `{ error: string }` 的联合对象，错误信息使用中文提示字符串而非抛出异常。
- 跨端复用的纯函数（如 `findSkillRoot`、`normalizeSkillPath`、`parseSkillMd`、`compareSkillVersions`）不依赖外部状态，注释中明确标注“服务端与浏览器共用”。
- Skill 相关常量以 `SKILL_` 前缀命名（大小、文件名、模式、标签等），并与对应解析/校验函数放在同一文件便于定位。
