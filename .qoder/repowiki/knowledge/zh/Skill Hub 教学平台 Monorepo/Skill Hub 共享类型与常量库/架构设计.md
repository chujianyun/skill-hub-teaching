该模块是一个被 `@skill-hub/shared` 发布的纯类型/工具库，无运行时依赖（仅 `yaml` 用于解析 SKILL.md frontmatter）。
- 入口 `src/index.ts` 通过 `export *` 聚合 `auth`、`tenant`、`skill` 三个子模块，并暴露全局常量 `API_PREFIX`、`HEALTH_PATH` 与 `HealthResponse`。
- `auth.ts` 定义会话 Cookie 名、登录请求/响应、`CurrentUser`、`EmployeeProfile` 及 `ApiErrorBody`，并提供 `canEnterTenant` 判定逻辑；`tenant.ts` 仅导出 `TenantStatus` 与 `Tenant` 类型供 auth 引用，形成单向依赖。
- `skill.ts` 是最大模块，集中 Skill 包的上传限制、路径规范化、SKILL.md frontmatter 解析、语义化版本解析与比较、可见性模型、分类、审核状态机、差异计算、预览等纯函数与类型，所有函数均无副作用，可在服务端与浏览器共用。
- 构建由 `tsup` 同时产出 ESM（`.mjs`）与 CJS（`.js`），并通过 `exports` 字段区分 `import`/`require` 的 types 入口，使上层以 `import` 或 `require` 方式消费同一份声明。
