- 所有后端请求统一走 `api.ts` 的 `api()` 函数，组件不直接调用 fetch，错误通过 `ApiError` 携带 status/code/body。
- 需要用户上下文的页面用 `RequireSession` 包裹路由元素，并在内部通过 `useCurrentUser` / `useCurrentEmployee` 读取身份信息。
- 页面级 UI 拆分为多个小文件（如 SkillManage/SkillParts/SkillFileViews/SkillVisibility 等），由父页面组合渲染，避免单文件膨胀。
- 全局状态通过 React Context + `useContext` 钩子暴露（`MeContext`、`SkillBadgesContext`），组件内仅消费对应 hook。
- 路由跳转前对 next 参数使用 `safeNext` 白名单校验，仅允许 `/admin|/tenant|/workspace|/skills` 开头的本地路径。
