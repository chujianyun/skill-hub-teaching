模块以 `src/App.tsx` 为路由入口，使用 react-router v7 的嵌套 `<Routes>` 划分 `/admin`（超管）、`/tenant`（租户管理员）和 `/workspace`（普通员工）三条控制台线，并通过 `RequireSession` 守卫统一鉴权。
- 状态层：`session.tsx` 通过 `MeContext` 暴露 `useCurrentUser` / `useCurrentEmployee` / `useSetMe`；`skillBadges.tsx` 通过 `SkillBadgesProvider` 在菜单上展示待审/驳回红点。
- API 层：`api.ts` 封装统一的 `api()` 调用（自动 JSON/FormData 区分、非 2xx 抛 `ApiError`），并提供 `logout` 与 `safeNext` 校验工具。
- 页面层：`src/pages/` 下按功能拆分（SkillsPage、MySkillsPage、SkillManage、SkillReviewPages、SkillParts、SkillFileViews、SkillVisibility、UploadSkillModal 等），由 `ConsoleLayout` 提供侧边栏布局。
- 构建与测试：Vite 开发服务器默认端口 5175，通过代理转发 `/api` 到 `API_TARGET`；Playwright E2E 在 `playwright.config.ts` 中启动后端 (`@skill-hub/server`) 与前端两个 webServer，并重置数据库后运行 `e2e/demo.spec.ts`。
