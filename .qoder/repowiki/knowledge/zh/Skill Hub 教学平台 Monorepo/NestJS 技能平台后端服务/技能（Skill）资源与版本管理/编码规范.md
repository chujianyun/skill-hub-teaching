- 控制器方法通过 `@TenantMember()` / `@TenantAdminOnly()` / `@SuperAdminOnly()` 装饰器声明权限，并在方法体内用 `@Auth()` 取 `auth.user.id`、`@CurrentEmployee()` 取员工上下文。
- 需要上传 zip 的接口统一使用 `@UseInterceptors(SkillUploadInterceptor)` 配合 `@UploadedFile()`，并通过 `requireFile(file)` 在缺失时抛出 400。
- 写库操作使用 `this.prisma.$transaction(async (tx) => ...)` 包裹，并发敏感路径（如上传新版本、删除版本、删除 Skill）先用 `SELECT ... FOR UPDATE` 锁住 Skill 行再执行后续校验与写入。
- 对「所有者或租户管理员」的操作统一调用 `assertCanManage(prisma, viewer, skill, message)`，该函数根据是否可见返回 404 或 403，避免暴露不存在资源。
- 变更类操作（修改可见性、修改分类、下架/上架、重新上传）在事务中同时写入业务数据并追加一条 `skillReviewRecord` 审计记录，action 字段区分具体动作。
- Skill 名称冲突与并发创建通过捕获 Prisma P2002 唯一约束错误后二次校验 `assertNameFree`，向客户端返回包含已有 Skill id 的 409 响应体。
