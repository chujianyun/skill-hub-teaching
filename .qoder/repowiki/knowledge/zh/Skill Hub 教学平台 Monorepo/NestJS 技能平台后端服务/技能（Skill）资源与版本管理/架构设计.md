基于 NestJS Module 组织，`skills.module.ts` 是入口，按固定顺序注册控制器以让 `/skills/manage`、`/skills/visibility-options`、`/skills/mine` 等固定路径先于 `:id` 通配路由匹配。

- 控制器层：`SkillsController`（租户成员）、`AdminSkillsController`（超管治理）、`SkillCategoriesController`、`SkillReviewsController`、`SkillReviewLinksController` 各自负责一组路由，仅做参数解析与鉴权装饰器转发。
- 服务层：`SkillsService` 承载核心领域逻辑（创建/更新/删除 Skill 与版本、可见性、下架/上架、下载计数），依赖 `PrismaService` 与 `PrivateFileStorage`；其余 `*Service` 文件分别处理分类、审核、审核链接子域。
- 横切工具文件：`skill-upload.ts` 复用 `fileUploadInterceptor` 限制 zip 大小并提供 `requireFile`；`skill-package.ts` 负责 SKILL.md 解析与打包；`skill-visibility.ts` 集中实现可见性校验、部门祖先链计算、`visibleSkillWhere` 查询条件与写入；`skill-views.ts` 提供 `canManage`、`findVisibleVersion`、`toVersionInfo` 等视图辅助；`skills.dto.ts` 定义 DTO 类型。
- 依赖方向单向：controller → service → (prisma + storage + skill-* utilities)，不反向引用。
