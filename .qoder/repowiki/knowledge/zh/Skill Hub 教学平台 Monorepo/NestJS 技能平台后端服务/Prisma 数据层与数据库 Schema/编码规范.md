- 实体主键统一采用 `String` 类型并配合 `@id @default(uuid())` 生成 UUID。
- 多对多可见性关系通过中间表模型（如 `SkillVisibleDepartment`、`SkillVisibleEmployee`）显式建模，并使用复合 `@@id` 与 `@@index`。
- 级联删除在强关联上配置 `onDelete: Cascade`（如 Session→User、SkillVersion→Skill），弱关联使用 `SetNull` 或 `Restrict`。
- 时间字段统一使用 `DateTime` 并搭配 `@default(now())` 与 `@updatedAt` 维护审计时间戳。
