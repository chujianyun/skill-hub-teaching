模块以 `AuthModule` 为装配入口，将 `AuthGuard` 通过 `APP_GUARD` 注册为全局守卫，使所有控制器默认需鉴权；`@Public()` 可豁免。
- 分层：`auth.controller.ts` 暴露 `/auth/login|logout|me` 三个 HTTP 端点，仅负责参数解析与 Cookie 读写；`auth.service.ts` 封装会话生命周期（生成随机 token、SHA-256 哈希后存入 `session` 表）以及按当前租户查询员工/管理员的领域逻辑；`auth.guard.ts` 作为统一鉴权入口，从 Cookie 中读取 `SESSION_COOKIE`，调用 `AuthService.authenticate` 反查会话并挂载到 `req.auth`。
- 权限模型：`decorators.ts` 定义 `IS_PUBLIC` / `SUPER_ADMIN_ONLY` / `TENANT_ADMIN_ONLY` / `TENANT_MEMBER` 四个元数据常量及对应装饰器，Guard 通过 `Reflector` 依次校验超管、租户管理员、租户成员三级权限，并在通过后向 `req.auth` 注入 `tenantAdmin` / `employee` 上下文。
- 类型扩展：`session.ts` 声明 `AuthContext` / `CurrentEmployeeContext` 并通过 `declare module 'express'` 给 Express `Request` 附加 `auth` 字段，供 Guard 与装饰器共享。
- 依赖方向：controller → service ← guard；service 依赖 `PrismaService` 与 `../seed/demo` 中的演示账号；对外仅导出 `AuthService`。
