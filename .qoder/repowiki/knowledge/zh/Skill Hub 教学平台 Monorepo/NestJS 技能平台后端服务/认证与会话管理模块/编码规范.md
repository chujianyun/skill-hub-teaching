- 鉴权元数据通过 `SetMetadata` 常量（如 `auth:isPublic`）配合装饰器工厂函数暴露，Guard 用 `Reflector.getAllAndOverride` 在 handler 与 class 两级读取。
- 鉴权结果统一挂载到 `req.auth`（`AuthContext`），并通过 `createParamDecorator` 提供 `@Auth()` 与 `@CurrentEmployee()` 两个参数装饰器供控制器消费。
- 敏感 Cookie（`SESSION_COOKIE`）的 `cookieOptions` 集中定义，统一设置 `httpOnly`、`sameSite: 'lax'` 与基于 `SESSION_COOKIE_SECURE` 的 `secure` 标志。
- 服务层方法对 `currentTenantId` 为空时直接返回空结果或 Promise.resolve(null)，避免在调用方重复判断租户是否已选择。
